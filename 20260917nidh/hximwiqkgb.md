# 营养专线 | 肿瘤患者必备营养知识

> 更新时间：2026-09-17 (UTC+8)

肿瘤是一种严重的疾病，治疗肿瘤需要耗费大量的精力和财力。

近年来，我国在肿瘤早期预防和控制方面做了很多工作，也取得了一定成效。但仍然有许多肿瘤很难做到早诊早治。
在面对这些肿瘤时，无论是手术还是放化疗，没有营养治疗的基础，治疗效果绝对是不好的，甚至是有反效果的。
肿瘤细胞的生长和扩散需要大量的营养物质，因此，正确的营养摄入对肿瘤患者的康复至关重要。

南京医科大学附属泰州人民医院肿瘤科主治医师夏阳：“有好几批晚期肿瘤患者，经过治疗，他们的情况有所恢复，但是由于营养没跟上，导致最终的治疗效果并不理想。这也让他意识到营养治疗的重要性，开始向相关专家请教，为患者科学地进行营养治疗。”

“今年我院肿瘤科挂牌国家营养治疗示范病房，对肿瘤患者的营养规范化治疗起到重要作用。夏阳医师表示，在肿瘤治疗中，除了手术、放化疗之外，营养治疗也一样重要。我经常跟肿瘤患者说，要注意营养的补充，保证蛋白质的摄入。鸡、鱼、羊肉等等，想吃什么就吃什么，能够吃进去东西是很关键的。”“对于肿瘤患者来说，营养治疗是基础。没有营养，患者就没有免疫力、没有抵抗力，手术、放化疗等治疗的效果可能就无法充分发挥。”
肿瘤患者的营养需求与普通人有所不同。
首先，肿瘤患者需要增加蛋白质的摄入量，以维持正常的身体功能。

其次，患者需要增加维生素和矿物质的摄入量，如维生素C、维生素E和硒等，以提高身体的免疫力，减轻化疗和放疗的副作用。
此外，患者还需要减少脂肪和胆固醇的摄入量，以减轻消化系统的负担。
**夏阳给肿瘤患者的饮食建议：**

1. 增加蛋白质的摄入量，如鱼类、瘦肉、豆类等。

2. 多吃新鲜水果和蔬菜，以增加维生素和矿物质的摄入量。

3. 避免油腻、辛辣和难以消化的食物，以免加重消化系统的负担。

4. 多喝水，保持充足的水分摄入，有助于减轻化疗和放疗的副作用。

“没有营养，健康就无从谈起。”正确的营养摄入对肿瘤患者的治疗和康复至关重要。了解肿瘤与营养素之间的关系，掌握肿瘤患者的营养需求和饮食建议，有助于帮助患者更好地应对疾病。肿瘤患者应在医生的指导下进行合理的营养补充，同时保持积极乐观的心态，增强战胜疾病的信心。
