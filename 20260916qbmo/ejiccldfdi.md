# 如何监测排卵？

> 更新时间：2026-09-16 (UTC+8)

对于有生育要求的女性朋友来说，抓住最佳时机“造人”尤为重要。而在临床工作，许多女性朋友不知如何监测自己的排卵期。今天，我们来学习如何监测排卵期。

01

—

**               卵泡的发育和成熟**

女性生育期卵巢每月发育一批卵泡（3~11个），经过募集、选择，其中一般只有一个优势卵泡可达完全成熟，并排出卵子。其余的卵泡发育到一定程度通过细胞凋亡机制而自行退化，称卵泡闭锁。

卵泡的发育：始基卵泡 → 窦前卵泡 → 窦状卵泡 → 排卵前卵泡 → 排卵。约在月经周期第7天，卵巢内被募集的一批卵泡会有一个卵泡优先发育成为优势卵泡，其余的卵泡逐渐退化闭锁，月经第11~13天，优势卵泡增大至18mm左右，进一步发育至排卵前卵泡（直径可达18~23mm），出现LH峰，36小时左右排卵。

02

—

                    **如何监测排卵？**

1、**基础体温测定**
正常每日清晨起床前的体温（即基础体温）在37度以下，约在36.4~36.6度左右。排卵时体温稍下降，排卵后体温平均上升0.3~0.5度左右，一直维持到月经来潮前才开始下降。在每天早晨醒后，不起床，最好在同一时间段，用口表测量体温，并记录在表格上。

**2、宫颈外口及粘液的观察**
月经干净后，随着卵泡的生长，分泌的雌激素水平不断提高，刺激宫颈腺细胞的分泌功能，至**排卵期**粘液分泌量增加，粘液稀薄、透明，拉丝度可达10cm以上。此时同房，有利于精子上行。
**3、监测尿LH峰**

月经周期28天的女性，以月经来潮第一天为第一天，第11天左右开始使用排卵试纸，若出现两条线，下面一条颜色比上面深或者一样，表示24~48小时到排卵高峰。这就是同房的最佳时机。

4、**B超监测卵泡的发育**
对于月经周期28天的女性，月经周期第7~8天卵巢会出现一个优势卵泡（约10mm），平均每日生长1mm，可2~3天B超监测卵泡发育，当卵泡生长至成熟卵泡（18~23mm），1~2天复查B超监测是否已排卵。对于月经周期规律的女性，一个月经周期B超监测排卵，可能需要就诊5-6次。结合排卵试纸的监测，就诊次数可适当减少。

 
这些方法您都掌握了么？若尝试后仍未孕的话，建议到专科医院就诊获得专科医师的师指导。一对生育力正常的夫妇每个月经周期的自然受孕率大约是20%~25%，婚后1年内初孕率为90%左右。育龄夫妇同居未避孕正常性生活未孕1年或以上者为不孕症，建议专科医院就诊。
